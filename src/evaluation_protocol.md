# Evaluation Protocol – Educational QA Chatbot

This document describes the evaluation methodology
used for the Retrieval-based Answering (RAQ) model.

## Metrics
- Exact Match (EM)
- F1-score

These metrics are standard for Question Answering
benchmarks such as SQuAD and FQuAD.

## Evaluation Strategy
- Evaluation performed on the test split
- Subsampling used for fast validation
- Answers generated via argmax decoding
